# Illustrator Guide

## Tujuan

Guide ini menjadi referensi ringan untuk Skill `ilustrator`. Skill bertugas menerjemahkan naskah komik menjadi ilustrasi serial yang konsisten dalam satu volume.

## Model Kontinuitas

```text
PROJECT VISUAL DNA
        |
        +-- EPISODE 1 CONTEXT
        |      +-- Page 1
        |      +-- Page 2
        |      +-- Page 3
        |      +-- ...
        |
        +-- EPISODE 2 CONTEXT
        |      +-- Page 1
        |      +-- Page 2
        |      +-- ...
        |
        +-- EPISODE N CONTEXT
```

Project Visual DNA tetap menjadi identitas visual utama. Episode Context dapat berubah sesuai cerita.

## Initial Input

Pengguna sebaiknya mengirim:

1. Project DNA / Continuity Bible.
2. Profil karakter dan desain visual karakter.
3. Gaya visual atau referensi style bila tersedia.
4. Ringkasan episode.
5. Naskah halaman secara berurutan.

Contoh struktur profil karakter:

```text
Nama:
Usia:
Ciri fisik:
Pakaian khas:
Aksesori/properti:
Kepribadian:
```

## Continuity Ledger

Ledger internal minimal mencatat:

- karakter yang aktif;
- pakaian dan aksesori;
- lokasi;
- waktu dan cuaca;
- properti;
- posisi/arah gerak;
- ekspresi dan keadaan emosional;
- kejadian terakhir;
- perubahan yang baru terjadi.

Ledger diperbarui setelah setiap halaman agar halaman berikutnya tidak memulai dari nol.

## Fixed vs Variable Character Attributes

### Fixed

- wajah;
- rambut;
- usia visual;
- bentuk tubuh;
- pakaian khas;
- aksesori khas;
- ciri identitas lainnya.

### Variable

- ekspresi;
- pose;
- aktivitas;
- posisi;
- pencahayaan;
- kondisi sementara akibat cerita.

Perubahan fixed attribute harus mempunyai dasar dari pengguna atau cerita.

## Prinsip Visual

- Gunakan desain karakter yang sama sepanjang volume.
- Jangan membuat karakter terlihat seperti orang berbeda hanya karena angle kamera berubah.
- Pertahankan skala relatif karakter.
- Pertahankan hubungan karakter dengan lokasi dan properti.
- Pertahankan waktu, cuaca, dan pencahayaan sampai cerita menyatakan perubahan.
- Pastikan arah aksi antar-panel masuk akal.
- Jangan menambahkan kejadian baru hanya demi membuat gambar lebih dramatis.

## Horror + Comedy + Adventure

Untuk horror ramah anak:

- suspense melalui atmosfer dan framing;
- bayangan dan pencahayaan untuk ketegangan;
- ekspresi takut yang tetap sesuai usia;
- humor melalui timing visual dan reaksi karakter;
- petualangan melalui eksplorasi, gerak, dan penemuan;
- hindari gore dan kekerasan grafis.

## Pergantian Episode

Saat pengguna menyatakan episode selesai:

1. berhenti menggunakan detail spesifik episode sebagai konteks aktif;
2. pertahankan Project Visual DNA;
3. simpan hanya konsekuensi cerita yang memang relevan untuk kontinuitas berikutnya;
4. saat episode baru diberikan, buat Episode Visual Context baru.

## Prioritas Konflik

Jika terdapat konflik informasi, gunakan urutan prioritas:

1. instruksi terbaru pengguna yang eksplisit;
2. naskah halaman terbaru;
3. continuity yang telah dikunci;
4. Project DNA;
5. asumsi visual umum.

Jika konflik tidak dapat diselesaikan dengan aman, tanyakan klarifikasi singkat.

## Output

Output utama adalah ilustrasi yang dapat langsung digunakan sebagai bagian dari produksi komik. Penjelasan teks harus singkat kecuali pengguna meminta analisis atau revisi.
